# Earth Seasons Axial Tilt Simulator

## 概要
地球の公転位置（0〜360°）スライダーで北半球・南半球の日照時間と太陽高度を計算・棒グラフ表示する天文教育ツール。季節ラベルと軌道図付き。

## 機能
- 公転角度スライダー（0〜360°）
- 北半球・南半球の日照時間計算（緯度45°基準）
- 太陽高度角計算
- 軌道図（地球の軸傾きを赤線で表示）
- 季節ラベル表示（春分・夏至・秋分・冬至）
- Chart.jsによる日照時間棒グラフ

## 使い方
スライダーを動かして地球の公転位置を変更します。左の軌道図で地球の位置と軸傾きを確認し、右のグラフで北半球・南半球の日照時間の変化を観察できます。
